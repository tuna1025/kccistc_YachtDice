# kccistc_YachtDice

## PySide6 UI

프로젝트용 Conda 환경에서 실행합니다.

`C:\ProgramData\anaconda3\envs\yacht_env\python.exe pyside6_main.py`

카메라 없이 디자인만 확인하려면 다음 미리보기 모드를 사용합니다.

`C:\ProgramData\anaconda3\envs\yacht_env\python.exe pyside6_main.py --preview`

창, 점수 선택, 애니메이션은 PySide6가 담당하고 OpenCV는 카메라, YOLO는 주사위 인식에만 사용합니다.
현실 주사위로 요트 다이스 게임 시 웹캠에 인식된 점수를 자동으로 배정해주는 프로그램
